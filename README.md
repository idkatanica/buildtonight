# Build Tonight

**What should you build tonight?**

Build Tonight is a macOS app for people who want to build something but don't know what. Answer a few
questions or type a loose direction, and it hands you a specific, buildable project: who it's for, the problem it
solves, a realistic MVP, a stack, a visual direction and the very first step. Then it turns the idea into a
build brief you can start on right away.

## Download

The first public release is on its way. Installers will appear on the
[Releases](https://github.com/idkatanica/buildtonight/releases) page.

## Requirements

- macOS 13 Ventura or later

## Installing

1. Download the latest `.dmg` from [Releases](https://github.com/idkatanica/buildtonight/releases).
2. Open it and drag **Build Tonight** into **Applications**.
3. Early builds aren't notarized yet. If macOS says the app can't be opened, go to
   **System Settings → Privacy & Security** and click **Open Anyway**.
